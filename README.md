# 🧮 Math Quiz Game (C++)

An interactive, console-based *Math Quiz Game* built in C++ using structured programming principles (*Divide & Conquer), Structs, and Enums. This project was developed as the second major project in the *Algorithms & Problem Solving Level 2 course (Programming Advices).

---

## ✨ Features

* *Customizable Quiz Settings:* Choose the number of questions, difficulty level, and arithmetic operation before starting.
* *4 Difficulty Levels:*
  * Easy: Numbers from 1 to 10
  * Med: Numbers from 10 to 50
  * Hard: Numbers from 50 to 100
  * Mix: Randomly mixes between Easy, Medium, and Hard questions
* *5 Operation Types:* Addition (+), Subtraction (-), Multiplication (*), Division (/), and Mix.
